ROBOTRADE AI AUTO — iPhone PWA (DEMONSTRAÇÃO)

1. Esta pasta é um site estático. Para instalar na tela inicial do iPhone, publique TODO o conteúdo em um endereço HTTPS (por exemplo, GitHub Pages, Netlify ou Cloudflare Pages). Abrir index.html como arquivo local não permite instalar uma PWA confiavelmente.
2. No iPhone, abra a URL HTTPS no Safari. Toque Compartilhar > Adicionar à Tela de Início > Adicionar.
3. Abra o ícone ROBOTRADE AI na tela inicial. Inicie a simulação.
4. Histórico e parâmetros ficam apenas no armazenamento local desse navegador/aplicativo. Limpar dados do Safari ou mudar de domínio pode apagar o histórico. Exporte CSV regularmente.
5. Não é um aplicativo da App Store. Não há API OpenAI, cotação real, integração com IQ Option, nem execução de ordens. Sinais e resultados são aleatórios, apenas para demonstrar gerenciamento.
6. iOS pode suspender a página em segundo plano. Ao reabrir após uma operação em andamento, o sistema cancela a operação simulada sem inventar resultado e permanece pausado. Para uso contínuo, mantenha a tela aberta.
7. Limites: entrada R$5; stop win +R$20; stop loss -R$15; máximo 10 operações; payout sintético 80% ajustável; M1; expiração 60 segundos.
